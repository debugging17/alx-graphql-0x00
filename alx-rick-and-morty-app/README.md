# alx-rick-and-morty-app

This project uses Next.js, TypeScript, ESLint, and Tailwind CSS for developing a Rick and Morty application.

## Setup Instructions

1. Create the project:
   ```
   npx create-next-app@latest alx-rick-and-morty-app --typescript
   cd alx-rick-and-morty-app
   ```

2. Install dependencies:
   ```
   npm install @apollo/client graphql
   npm install @types/graphql
   ```

3. Create a `graphql` directory in the project root.

4. Add `apolloClient.ts` and `queries.ts` as described.

5. Replace the content of `pages/_app.tsx` as shown below.

6. Run the application:
   ```
   npm run dev
   ```

7. Open [http://localhost:3000](http://localhost:3000) in your browser.
